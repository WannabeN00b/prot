## Liquid Cursor
This portfolio uses Cravin' Adventure Studios' `liquid-cursor` v1.0.1 via jsDelivr. It is a dependency-free GPU fluid cursor trail licensed under MIT. Configuration: curl 30, radius 0.25, dye resolution 512, simulation resolution 140, pointer-only drift, and a WANNABENOOB red palette.


Cursor: lightweight CSS/JS negative-color glow. It uses mix-blend-mode:difference so the glow inverts only the pixels underneath the pointer. No WebGL, Three.js, CDN, or heavy animation.
